# 거꾸로 신분증 — 사칭 차단 QR · PoC 데모

2026 모바일신분증 아이디어 공모전 응모작 「거꾸로 신분증 — 시민이 공무원의 신분을 확인하는 사칭 차단 QR」의 개념검증(PoC) 시연 페이지입니다.

- 데모: https://gooreum.github.io/geokkuro-poc/
- 휴대폰 카메라로 데모 화면 ②의 QR을 찍으면 `check.html`(시민 확인 화면)이 열리고, 휴대폰 브라우저 안에서 기관 서명·직원 단말 서명·시각(30초)·폐지 여부·재사용을 검증해 초록/빨강으로 알려 줍니다. 앱 설치가 필요 없습니다.
- 장면 6개를 차례로 찍어 봅니다. 📞 전화가 왔을 때: 진짜 직원의 1회용 확인번호 / 사기범이 지어낸 번호 · 🚪 직접 만났을 때: 진짜 직원 / 가짜 '경찰서'(위조 서명) / 1분 전 캡처(만료) / 퇴직자(폐지목록)
- 전화 확인번호(`call.mjs`): 서버가 없는 정적 데모라 '기관 서버'를 공개 데모 키(`call-key.json`)의 HMAC 으로 흉내 냅니다(직원ID·60초 구간 → 6자리). 실서비스에서는 기관 서버만 키를 가집니다.

시연용 모의 환경입니다. 기관 키(`demo-issuer-key.json`)는 공개된 데모 키이고, 기관·직원 정보는 가상입니다. 실제 모바일신분증·인사시스템과 연동하지 않았습니다.
프로토콜: WebCrypto ECDSA P-256 (`protocol.mjs`). QR 생성: qrcode-generator (MIT, `vendor/qrcode.js`).
코드 작성에 생성형 AI(Anthropic Claude)를 보조 도구로 사용했습니다.
