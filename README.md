## 1차 피드백 반영

- 토스트 3초 후 제거. 장면 이동·새 결과 표시 때 즉시 제거. 초록 결과에는 이전 신고 토스트가 남지 않음.
- 빨강 결과의 기관 신고는 버튼 → 내용·동의 → 전송으로만 발생. 중복 전송 금지. 오프라인 신고는 ‘전송 대기’로 저장하며 연결 후 사용자가 다시 보냄.
- 설명 패널 ‘시연 안내’, 9개의 원형 진행점. 의미 없는 두 줄 막대 제거.
- 데스크톱 휴대폰 높이는 `min(680px, 100dvh - 160px)`. 1280×800의 하단 고지 영역을 확보.
- 결과에서는 탭바 숨김. 내부 세로 스크롤과 하단 여백으로 모든 버튼 접근 가능.
- 위조/캡처/퇴직자의 상대 화면과 실제 검증 토큰 구분. 사칭 전화에 걸려 온 전화 카드 제공.
- 모바일 전화번호 카드·큰 입력 보조 버튼. 잠금은 다섯 번째 오입력부터 5분, localStorage에 보존.
- 카메라 거부와 통신 끊김을 별도 탭·상태로 분리.
- 관리자 발급 폼·직원번호 검증·폐지 확인 바텀시트, 검색·빈 상태 구현.

## 구현과 파일

- `index.html`, `check.html`: 시연 앱과 실폰 QR 링크용 단독 검증 화면.
- `style.css`: 모바일 우선 토큰, 휴대폰 프레임·역할 카드·결과·바텀시트·토스트·스켈레톤·인쇄 레이아웃.
- `app.js`: 9장면, 해시 라우팅, 실제 검증, 신고·직원·기록 상태, 공유·CSV·인쇄.
- `data.js`, `trust.json`, `revoked.json`, `demo-issuer-key.json`: 공개 시험 자산. **공개된 테스트 발급키이며 실서비스에 사용하지 않습니다.**
- `protocol.mjs`: 기존 PoC ECDSA P-256 프로토콜과 동일. HTTPS에서는 실제 모듈을 import합니다.
- `protocol.browser.js`: 같은 모듈에서 export만 제거해 IIFE로 감싼 파일. file://에서 모듈 CORS 문제 없이 동일 검증을 실행합니다. 검증 스크립트에서 소스·API 동등성 검사.
- `fonts/`: Pretendard 가변 WOFF2와 OFL 라이선스.
- `vendor/`: qrcode-generator와 MIT 라이선스.
- `LICENSE-icons.txt`: 이전 제작물에서 재사용한 자체 SVG 경로의 MIT 라이선스.
- `verify.mjs`, `verify-ui.cjs`: 프로토콜 회귀와 DOM 상태 검사.
- `shot.mjs`: 바깥 Claude가 실행할 브라우저 촬영·assertion 스크립트.

실폰 QR에는 상대경로로 계산한 `check.html#<서명 토큰>`이 들어갑니다. file://에서 제시한 QR은 공개 경로 `https://gooreum.github.io/geokkuro-poc/check.html`로 연결됩니다. HTTPS 하위 경로에서 배포하면 현재 경로의 check.html을 사용합니다. 새 파일의 GitHub Pages 반영은 아직 수행하지 않았습니다.

## 바깥 Claude의 브라우저 촬영

요청대로 이 단계에서는 **shot.mjs를 실행하지 않았습니다**. 실제 렌더링의 가로 넘침·footer 위치·초점·브라우저 뒤로가기·음성·공유·실폰 카메라는 후속 실기기/브라우저 확인이 필요합니다. DOM 테스트의 ‘별도 휴대폰’은 서로 독립된 DOM·저장소를 뜻하며 실제 휴대폰 촬영 결과가 아닙니다.

```sh
PW_ROOT=/absolute/path/to/node_modules node poc/web/shot.mjs
# 배포 후에는 선택적으로:
DEMO_URL=https://gooreum.github.io/geokkuro-poc/index.html PW_ROOT=/absolute/path/to/node_modules node poc/web/shot.mjs
```

요청한 로딩 방식 `createRequire(process.env.PW_ROOT + '/')('playwright')`을 사용합니다. 장면별 390×844 / 1280×800 촬영, 초기 화면 `demo-<장면>-<폭>.png`, 결과 `-result`, 신고 `-reported`, 잠금 `-locked`, 카메라 거부 `-camera-denied`, 오프라인 번호/QR, 발급 폼/폐지 확인/관리자 신고를 `../../_codex/shots/`에 저장합니다. `demo-checks.json`은 가로 넘침·desktop footer 잘림·상태 assertion·런타임 오류를 기록합니다. 기존 shots의 파일은 ROUND 1이므로 새 촬영 전에는 2차 검증 자료로 사용하지 마세요.

## 모의 범위

실제 모바일신분증·인사시스템·기관 서버에 연결하지 않습니다. QR 버튼은 화면에 제시된 토큰을 전달하며 실제 카메라 인식을 수행했다고 표현하지 않습니다. 권한 선택은 앱의 권한 안내 흐름입니다. 전화번호 발급 서버와 신고 전송은 브라우저 내부 모델입니다. 오프라인 검증은 저장한 신뢰·폐지목록에 한하며 마지막 동기화 이후 변경사항을 알 수 없습니다. 신규 발급·폐지는 같은 브라우저 저장소에서 공유되며 다른 기기에는 기관 서버 없이 전파되지 않습니다.

가족 공유는 사용자가 공유 화면에서 수신자를 정합니다. 112 버튼은 안내 바텀시트에서 한 번 더 선택해야 전화 앱을 엽니다. 기록 PDF는 브라우저 인쇄의 PDF 저장 기능을 사용합니다. 확인·신고 기록은 브라우저에 30일 보관하고 재실행 시 지난 항목을 제거합니다. 실제 운영용 인증·보안영역 키 관리·권한 체계는 구현 범위 밖입니다.
